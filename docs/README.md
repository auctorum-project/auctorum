# Documentación AUCTORUM

## Estructura

### `/fundacional`
Documentos fundacionales del proyecto — visión, misión, y constitución técnica.

### `/arquitectura`
Documentación técnica de la arquitectura del sistema, diagramas, y especificaciones.

### `/roadmap`
Plan de ejecución por fases y roadmap de desarrollo.

### `/bitacoras`
Bitácoras diarias de desarrollo — registro cronológico del progreso del proyecto.

### `/presentacion`
Material de presentación del proyecto.
